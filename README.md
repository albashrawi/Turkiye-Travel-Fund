## 01 — الحكاية

ما قد سافرت خارج السعودية من قبل.

ومع دخولي المرحلة الجامعية، قررت أبدأ أجمع مبلغ بسيط كل شهر، عشان أحقق واحد من الأشياء اللي تمنيتها من زمان: السفر واستكشاف العالم.

كانت تركيا أول وجهة شدتني؛ طبيعتها، مدنها، تاريخها، والأماكن اللي عرفتها من المسلسلات التركية.

ومن هنا بدأت فكرة **Türkiye Travel Fund**.

مو مجرد حاسبة ادخار، بل مساحة أتابع فيها رحلتي من أول مبلغ أجمعه إلى يوم السفر.

| Achievements | إنجازات وتحفيزات |
| Backup System | تصدير واستيراد البيانات |

## 03 — فلسفة الادخار

الخطة مبنية على مبدأ بسيط:

**الاستمرارية أهم من حجم المبلغ.**

- خلال الدراسة: 200 ريال شهرياً.
- خلال الإجازة الصيفية: 500 ريال شهرياً.
- أي مبلغ إضافي يمكن أن يسرّع الوصول للهدف أو يرفع ميزانية الرحلة.

جميع هذه القيم قابلة للتعديل من داخل لوحة التحكم.

## 06 — التشغيل

لا تحتاج إلى تثبيت أي حزم.

1. حمّل ملفات المشروع.
2. افتح `index.html`.
3. ابدأ بإضافة إيداعاتك ومتابعة تقدمك.

### النشر

يمكن نشر المشروع مجاناً عبر GitHub Pages:

`Settings → Pages → Deploy from a branch → main → /(root)`

---

## 07 — البيانات والخصوصية

يتم حفظ البيانات محلياً باستخدام `LocalStorage`.

- لا يحتاج المشروع إلى حساب.
- لا توجد قاعدة بيانات خارجية.
- لا تتم مزامنة البيانات تلقائياً بين الأجهزة.
- يمكن تصدير نسخة احتياطية واستعادتها لاحقاً.
